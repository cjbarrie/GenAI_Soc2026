# Shared OpenRouter key — instructor checklist

- Distribute outside the repository and learning materials.
- Use a course-specific key with a spending cap.
- Restrict providers/models where the account controls permit it.
- Tell students never to submit identifiable or sensitive field data through the shared gateway.
- Rotate immediately if the key appears in a notebook, screenshot, chat, or Git history.
- Inspect usage regularly and retire the key after the course.
- Required exercises use cached output, so revoking the key does not block assessment.

The model identifier, provider route, date, parameters, prompt, raw response, and relevant privacy decision belong in the research record; the credential does not.
