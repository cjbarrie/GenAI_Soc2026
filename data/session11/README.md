# Week 11 teaching data

`hofmann_habitual_pairs.txt` is copied from `data/pairs/habitual.txt` in
Valentin Hofmann's public `dialect-prejudice` replication repository at commit
`61e6421c7892bd229f88658b9d1f3f700df75e5e`.

Repository: https://github.com/valentinhofmann/dialect-prejudice

The authors distribute the repository under the MIT License, reproduced in
`HOFMANN_REPOSITORY_LICENSE.txt`.

The Week 11 classroom routine uses a small subset of these published
meaning-matched pairs. It asks a chat model to choose an occupation from a
fixed list and to explain the choice. This is a teaching demonstration, not a
replication of Hofmann et al. (2024). The published paper compares model token
probabilities under a matched-guise design and calibrates decision tokens.
