# Session 4 data provenance

All records in this directory are instructor-authored synthetic course materials.

- `confrontation_sequences.json` contains two constructed endings to one non-graphic confrontation. No real people, organization, protest, police unit, injury, testimony, or model response is represented.
- `deescalation_synthetic.aiff` and `escalation_synthetic.aiff` are text-to-speech audio descriptions generated locally with the macOS Samantha voice on 2026-08-21. They are accessibility-oriented descriptions, not recordings or simulations of a real confrontation.
- The illustrated storyboard is stored in `slides/session04/images/synthetic_confrontation_storyboard.png`. It was generated with OpenAI image generation from an instructor-authored prompt and contains no identifiable real people.

The paired endings are not an experiment and cannot establish intention, blame, responsibility, a causal mechanism, the validity of Collins's theory, or a population pattern.
