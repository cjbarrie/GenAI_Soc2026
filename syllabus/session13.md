**Date:** Wednesday, December 2, 2026 · 9:30 a.m.–12:15 p.m.  
**Course movement:** Delegate and audit  
**Methodological domain:** Auditing LLMs as objects of study

## Substantive question

What culture, ideology, and hierarchy are encoded in models?

## Learning objectives

By the end, students should be able to:

1. state the inferential target: predeclare and summarize a factorial audit across model, language, and user frame.
2. explain the reading disagreement in their own words;
3. identify the Python type of every major input and output in the worked trace;
4. trace one model–prompt condition through a nested loop and into a result table;
5. use the validation diagnostic to bound a sociological claim.

## Lecture argument

An output difference is an audit finding; explaining its social cause requires a stronger design. Cross-national and creator-geography comparisons identify patterned outputs; causal triangulation and the provisional consciousness study raise different evidentiary thresholds for explaining those patterns.

## Computational trace

Planned: students run structured-output calls over a small supplied grid of model and prompt conditions. A short loop preserves every condition and return in a table for predeclared comparisons.

## Weekly completion task

Planned: submit a narrated screen recording showing which parameter changes in each call, explaining the structured return and comparing two cells without assigning an unsupported social cause. Upload to the Box folder supplied by the instructor.

## Validation focus

A single English prompt difference is attributed to national culture, creator ideology, or alignment policy without isolating alternatives.
