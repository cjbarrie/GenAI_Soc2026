## Substantive question

What changes when the model becomes an interactant?

## Learning objectives

By the end, students should be able to:

1. state the inferential target: represent the experienced interaction rather than recording only the assigned condition.
2. explain the reading disagreement in their own words;
3. identify the Python type of every major input and output in the worked trace;
4. explain each line or small block of `summarize_exposure`;
5. use the validation diagnostic to bound a sociological claim.

## Lecture argument

In conversation, assignment is fixed but exposure emerges turn by turn from both participants. Persuasion studies isolate model and dialogue levers; relational studies show that disclosure and perceived authorship can change the treatment itself.

## Computational trace

Students move from visible synthetic inputs through `summarize_exposure` to a printed output and explicit checks. The required task uses no live API. Every code block is read as **input → Python type → operation → output → research meaning**.

## Weekly completion task

Convert ordered dialogue turns into a transparent exposure summary. Submit a prediction, working code, interpreted check, and 100–150 word reading-linked claim. Completion marks only; missing elements may be supplied within one week.

## Validation focus

A study labels everyone as receiving the same treatment despite different numbers, topics, and factual claims across conversations.
