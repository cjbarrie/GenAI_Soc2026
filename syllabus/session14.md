## Substantive question

What standards of evidence should govern LLM-assisted sociology?

## Learning objectives

By the end, students should be able to:

1. state the inferential target: audit one project record from claim through target, evidence, failure mode, and replication record.
2. explain the reading disagreement in their own words;
3. identify the Python type of every major input and output in the worked trace;
4. explain each line or small block of `audit_project_claim`;
5. use the validation diagnostic to bound a sociological claim.

## Required readings

- [Course synthesis: revisit one earlier empirical claim](../literature/literature_audit.md)

## Lecture argument

The strongest course outcome is not a more confident claim, but a claim whose scope matches its actual evidence. Across the semester, models make new transformations feasible while repeatedly moving validation and responsibility downstream to the researcher.

## Computational trace

Students move from visible synthetic inputs through `audit_project_claim` to a printed output and explicit checks. The required task uses no live API. Every code block is read as **input → Python type → operation → output → research meaning**.

## Weekly completion task

Return a missing-evidence checklist and a bounded revision prompt for one project claim. Submit a prediction, working code, interpreted check, and 100–150 word reading-linked claim. Completion marks only; missing elements may be supplied within one week.

## Validation focus

A project reports an LLM capability but never states the sociological inference, reference evidence, or boundary of the claim.
